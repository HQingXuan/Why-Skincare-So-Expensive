# 为什么 La Mer、SK-II 和赫莲娜这么贵？

这份调查起于一个很实际的问题：家里的护肤品为什么能卖到这个价格？消费者买到的是更好的技术、更好的效果，还是更强的品牌？

**结论：这些品牌有真实的研发、专有原料和配方技术；但“有技术”和“值得这个价差”是两回事。公开资料支持部分保湿、屏障和外观改善，却不足以证明这些代表产品在日常使用中，比合适的低价产品具有与售价差距相称的优势。品牌定位、营销、销售渠道、服务和使用体验，是理解价格的重要部分；现有资料无法给出“某一瓶有多少百分比是品牌溢价”。**

调查日期：**2026-10-10**。以下优先使用品牌产品页、原始研究和公司财报。品牌资料用于核对配方和宣传，论文用于判断实验支持到哪一步，财报用于理解商业模式；它们不能互相替代。

## 2. 护肤品的科技，究竟在解决什么问题？

护肤配方要让成分在实际使用中发挥作用，同时兼顾肤感、保存、批次一致性和微生物控制。只比较原料名称，会漏掉整个配方的工程工作。FDA 的化妆品生产检查指南就涉及原料和成品检验、防腐有效性、留样和批次记录。这些工作确实有价值，也不是奢侈品牌独有的能力。[FDA 生产与质量控制指南](https://www.fda.gov/cosmetics/cosmetics-guidance-documents/good-manufacturing-practice-gmp-guidelinesinspection-checklist-cosmetics)

基础原料也能有效。美国皮肤科学会列出的保湿成分包括甘油、矿物油、凡士林和聚二甲基硅氧烷；1992 年的人体研究也观察到凡士林促进实验性屏障损伤后的恢复。因此，“原料常见”不等于“没用”，也不能证明一瓶奢侈面霜就是某款便宜面霜的复制品。[AAD 干燥皮肤指南](https://www.aad.org/public/everyday-care/skin-care-basics/dry/dermatologists-tips-relieve-dry-skin)、[凡士林原始研究](https://pubmed.ncbi.nlm.nih.gov/1564142/)

评价高价技术时，应把四个问题分开：

| 要回答的问题 | 所需证据 | 不能直接推出什么 |
| --- | --- | --- |
| 成分有没有合理机制？ | 细胞、组织或化学研究 | 人脸上一定有明显效果 |
| 成品用后有没有改善？ | 人体测量、使用前后观察 | 改善由某个明星成分单独造成 |
| 成品是否优于基础配方？ | 随机、盲法、合适对照 | 优于所有其他产品或适合所有人 |
| 多花钱是否带来值得的改善？ | 同用途产品直接比较、效果大小、耐受与成本 | 仅凭专利数量或“临床验证”就值得价差 |

“使用后改善”尤其容易被误读：改善可能来自整个保湿体系，而非宣传最响亮的成分。试验还要区分消费者自评、仪器测量、专家评分，以及真实生活中能否看出差别。统计显著并不自动代表改善很大。

## 3. La Mer：有研究，但不能从海藻故事直接跳到价格合理

经典面霜的官网成分表前列包括 **Algae Extract、Mineral Oil、Petrolatum、Glycerin**。它同时含有香精等成分。这里既有品牌特色原料，也有常见保湿基础；成分表没有公开每项浓度，无法据此计算原料成本或拆分各成分的贡献。当前页面还注明 42 名女性的两周屏障测试、56 名女性的细纹测试，但没有完整展示对照方案。[经典面霜配方与试验脚注](https://www.cremedelamer.com/product/5834/12343/face/moisturizers/creme-de-la-mer)

品牌称 Miracle Broth 经约四个月的发酵制备。这是其工艺叙述，提示有专有生产过程；但发酵时间长、手工流程或故事独特，并不直接证明更强的临床效果，也不能算出这项工艺增加了多少单瓶成本。[La Mer 工艺介绍](https://www.cremedelamer.com/our-craft)

**不能说 La Mer 完全没有人体研究。**2023 年论文研究含巨藻发酵物的两种面霜，包含小规模随机双盲刺激性红斑试验，以及 58 人、53 人的十二周抗老观察。后两项报告了外观改善，但没有交代可用于判断价差的平价面霜并行对照。作者披露 La Mer 资助、咨询费及雅诗兰黛员工参与；正文以 cream 1/2 称呼产品，本文未确认与当前售卖配方完全一致。[Gold 等，2023，原始论文](https://onlinelibrary.wiley.com/doi/full/10.1111/jocd.15986)

2025 年另一篇品牌相关研究还将含巨藻发酵物的**精华**与基础保湿霜进行激光后分脸对照，29 人试验中，部分时间段的屏障恢复优于对照。这是实际存在的比较证据，但产品和使用场景都与经典面霜日常抗老不同。[Santhanam 等，2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC11741175/)

**判断：**有支持保湿、屏障和部分外观改善的资料；目前核查的证据不足以把当前经典面霜的高价解释为已证明的日常抗老优势。品牌资助不等于研究无效，但需要独立复现和直接产品比较。

## 4. SK-II：PITERA 有机制研究，但“90%”容易让人误解

美国官网将 PITERA 标为 **Galactomyces Ferment Filtrate，半乳糖酵母样菌发酵产物滤液**，配方还有丁二醇、戊二醇、水和防腐成分。品牌所称“超过 90% PITERA”指这种发酵滤液的比例，**不是 90% 某一种纯抗老分子**；不能与纯活性成分的浓度直接比较。[SK-II 美国配方与产品页](https://www.sk-ii.com/products/facial-treatment-essence)

这也不是只有一个故事。2024 年原始研究在角质形成细胞与离体皮肤中观察到 GFF 对分化、细胞连接及应激反应的影响，作者来自 P&G。这支持生物学机制，但不直接测量消费者使用神仙水后相对于另一款精华露的收益。[Snowball 等，2024](https://pubmed.ncbi.nlm.nih.gov/38924095/)

人体证据中，2023 年一项研究让 86 名女性同时使用**神仙水、另一款精华和面霜三件产品**十二个月，观察到皱纹、色斑、粗糙度等指标改善。它没有同期随机对照，不能把效果单独归给神仙水或 PITERA。“十一年纵向研究”指先比较 1999 与 2010 年的皮肤，再做一年产品干预，并不是连续十一年的随机产品试验。论文声明无外部资助，但作者为 P&G 员工或顾问，不能因此视为独立研究。[Miyamoto 等，2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC9917576/)

另一个很直观的例子是新加坡官网的一周改善百分比：脚注说明来自 **60 名日本女性的消费者自评**，不是与其他产品盲法比较的仪器结果。[SK-II 新加坡产品页及脚注](https://www.sk-ii.com.sg/product/facial-treatment-essence)

**判断：**专有发酵过程与机制研究构成真实技术基础；公开证据仍不足以证明神仙水单品相对于更便宜精华露的额外功效足以解释价差。反过来，同样写着 GFF 的其他产品，也不能只凭成分名称就认定与 PITERA 等效。

## 5. 赫莲娜：玻色因是真实研发，“30%”却不是纯分子浓度

Pro-Xylane 的配方成分名是 **Hydroxypropyl Tetrahydropyrantriol，羟丙基四氢吡喃三醇**。欧莱雅的技术介绍引用重建皮肤研究，讨论它对蛋白聚糖及皮肤连接结构的作用。这些是可研究的化学与生物学问题，而非仅有一个商标。[欧莱雅技术介绍与原始研究出处](https://www.lorealparisusa.com/ingredient-library/pro-xylane)

30PX 产品页脚注明确：**30% 指由水、HPT 和丙二醇组成的原料溶液添加量**。若纯分子在该原料中的质量分数为 `q`，在一致质量口径下，成品中的纯分子比例才是 `30% × q`。官网没有在这条说明中披露 `q`，本文不推测实际纯分子浓度。[30PX 官方定义](https://www.helenarubinstein.com/int/skincare/by-range/replasty/replasty-age-recovery-night-cream/HR-000022.html)

英国页面列出的术后使用自评来自两项各 30 人的研究：2011 年法国研究观察即时和 28 天结果，2018 年中国研究观察美容干预后 14 天结果。它们能说明参与者的体验，不能当成健康皮肤日常抗老优于平价面霜的证明。[研究脚注与自评结果](https://www.helenarubinstein.co.uk/skincare/by-franchise/replasty/replasty-age-recovery-night-cream/HR-000022.html)

**玻色因相关配方也确实有随机对照证据。**2017 年薇姿资助的研究招募 240 名绝经后女性，比较“含 3% 玻色因及其他成分的精华 + 保湿霜”与仅用保湿霜，60 天后部分外观评分更好，但紧实度、颈纹与干燥改善相近。它研究的是复合配方，无法分离玻色因贡献，也不是黑绷带成品。[Bouloc 等，2017](https://www.medicaljournals.se/acta/content/html/10.2340/00015555-2572)

2025 年发表的另一项随机双盲分脸试验，将 **10% HPT + 3% 烟酰胺**配方与 Aquaphor 对照，用于激光后护理，发现部分抗老评分优势。研究由欧莱雅资助；它同样不能替代黑绷带在日常使用条件下的试验。[HPT/烟酰胺原始试验](https://pmc.ncbi.nlm.nih.gov/articles/PMC12871497/)

**判断：**玻色因的研究基础和包覆肤感配方都有实际内容；但原料溶液百分比、术后自评和高价之间，仍缺少直接的功效与成本比较。也不能把其他含玻色因配方的研究自动算到黑绷带身上。

## 6. 钱去了哪里？财报比“原料只值几块钱”更可靠

三个品牌分别属于 [雅诗兰黛集团的 La Mer](https://investors.elcompanies.com/en/investors/investor-resources/faqs)、[P&G 的 SK-II](https://us.pg.com/brands/) 和 [欧莱雅高档化妆品部的赫莲娜](https://www.loreal.com/en/luxe-division/helena-rubinstein/)。研发平台、销售网络和品牌经营共同构成产品业务。

欧莱雅 **2025 日历年度**集团财报提供了一个可核查的例子。以下全部使用同一年度、同一集团和同一净销售额口径，金额单位为**百万欧元**；这不是赫莲娜单品牌数据。[欧莱雅 2025 年报损益表](https://www.loreal-finance.com/eng/2025-universal-registration-document/en/article/46/)

| 项目 | 金额 | 占集团净销售额 |
| --- | ---: | ---: |
| 净销售额 | 44,052.0 | 100% |
| 销售成本 | 11,313.4 | 25.7% |
| 研发与创新费用 | 1,380.6 | 3.1% |
| 广告与促销费用 | 14,177.8 | 32.2% |
| 销售、一般与管理费用 | 约 8,288 | 18.8% |
| 营业利润 | 8,891.9 | 20.2% |

按财报金额计算，`14,177.8 / 1,380.6 ≈ 10.3`：广告促销费用约为研发与创新费用的 **10.3 倍**。这说明品牌传播和销售投入是这一商业模式的重要部分；不能据此说“每瓶有 32.2% 是广告”，更不能说“其余 96.9% 都是品牌溢价”。

同样，欧莱雅 74.3% 的毛利率，或雅诗兰黛截至 **2026-06-30 财年**的 75.5% 毛利率，都不是净利润率。毛利之后还要支付研发、营销、管理等费用；集团确认的收入也不一定等于消费者付给零售商的价格。两个集团的期间不同，这里只说明会计概念，不做盈利能力排名。[欧莱雅年度业绩](https://www.loreal-finance.com/eng/press-release/2025-annual-results)、[雅诗兰黛 FY2026 业绩](https://investors.elcompanies.com/en/news-and-media/newsroom/press-releases/2026/08-19-2026-110037466)

**解释价格时，成本和定价要分开。**研发、生产、包装、销售服务确实需要钱；消费者愿意为品牌、体验和信任多付多少，则影响企业能定到什么价格。财报显示营销投入的重要性，公开功效研究又没有建立相称的产品优势，因此本调查认为：只用“昂贵科技”解释这些售价并不充分。这是证据支持的解释，不是对单瓶利润或品牌溢价比例的测算。

## 7. 哪些常见说法经不起核查？

| 常见说法 | 更准确的理解 |
| --- | --- |
| 贵，所以一定效果更强 | 售价不是临床比较；应看同用途成品的直接试验 |
| 含矿物油或凡士林，所以是骗局 | 常见原料有保湿价值；问题是额外收益是否值得价差 |
| 两款成分表相似，所以就是同一瓶 | 浓度、工艺和整个配方可能不同；相似不等于等效 |
| 专利多，所以抗老领先 | 专利数量不能替代成品功效比较 |
| “临床验证”意味着大型独立随机试验 | 可能是小样本、前后观察、消费者自评或品牌相关研究 |
| “30% 玻色因”或“90% PITERA”是纯活性浓度 | 要核对品牌对原料溶液、发酵滤液的定义 |

成分表也不是完整配方。在美国标示规则下，通常按含量递减排列，但不超过 1% 的成分可在后段任意排序；看位置无法精确倒推出浓度。[FDA 成分标示指南](https://www.fda.gov/cosmetics/cosmetics-labeling-regulations/cosmetics-labeling-guide)

“化妆品”“临床验证”和药品审批也不能混为一谈。FDA 说明普通化妆品和大多数成分通常不需要上市前批准；这一点不意味着产品不受监管或无须安全依据。本文讨论的是美国规则，不能直接套用其他地区。[FDA 化妆品成分说明](https://www.fda.gov/cosmetics/cosmetic-products-ingredients/cosmetic-ingredients)

## 8. 普通消费者怎样判断值不值？

先确定买它要解决什么问题：缓解干燥、改善某项外观，还是享受气味、肤感、包装和服务？使用体验本来就是消费价值的一部分；需要核实的是，把它说成更强功效时，证据是否跟得上。

对于基础保湿，皮肤科学会已经给出不依赖奢侈品牌的成分与配方选择原则。对于长期光老化，2013 年一项 **903 人、4.5 年**的随机试验比较规律防晒和自行决定防晒，支持规律防晒减缓皮肤老化；它测量的是手背皮肤微表面变化，不是直接对比这些奢侈面霜，也不是“皱纹减少 24%”的证明。[AAD 保湿指南](https://www.aad.org/public/everyday-care/skin-care-basics/dry/dermatologists-tips-relieve-dry-skin)、[Hughes 等防晒原始试验](https://pubmed.ncbi.nlm.nih.gov/23732711/)

算预算时，用实际消耗而非瓶子外观：`每月成本 = 实付价格 ÷ 实际用完天数 × 30`。例如，**假设** US$390 的一罐面霜用 90 天，每月成本约 US$130；若同样能满足需求的另一款产品每月 US$20，额外支出便是每月 US$110。后一个价格仅为计算示例，不是已验证的等效替代品。

可以一次只改变一件产品，保持其他习惯大致稳定，分别记录舒适度、刺激、肤感和你关心的外观变化。个人记录有助于决定是否复购，但不等同于盲法临床试验。我们没有你太太的具体产品清单、皮肤情况和使用反馈，因此不对她正在使用的产品作个体结论。

这份调查主要覆盖护肤品。粉底、口红等彩妆应另外比较色号、遮盖、持妆和使用体验；这里的抗老证据不能替它们回答“值不值”。

## 9. 调查边界与后续验证

本调查是一轮针对代表产品的公开资料核查，**不是系统综述**。检索包含产品名及 Miracle Broth / Macrocystis pyrifera ferment、PITERA / Galactomyces ferment filtrate、Pro-Xylane / Hydroxypropyl Tetrahydropyrantriol，与 clinical、randomized、controlled 等词的组合，并核对官网脚注和论文利益冲突。主要来源覆盖品牌官网、PubMed/PMC、论文出版方、FDA、AAD 和集团财报。

最重要的缺口是：当前售卖版本与论文配方的对应关系、充分的独立复现，以及这些单品与合适低价成品的直接比较。未找到充分证据，不等于证明产品无效；研究用了某个成分，也不等于验证含该成分的所有产品。

若继续调查，最有价值的输入是**具体产品全名、版本、容量、购买地区、实付价格和使用目的**。这样才能把“这个品牌很贵”变成可回答的问题：“为了这个用途，这一件产品多花的钱，换来了哪些可观察的收益？”
